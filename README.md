# Программа для изучения работы с файлами

**Выполняет задачи:**
1) Поиск в текущей директории всех файлов с именем 'task_*' и расширением 'md'
2) Извлечение из каждого файла блоков: "Номер задачи", "Задание" и "Решение"
3) На первом этапе: запись этих блоков в файл(на последующих этапах в базу данных)
4) Сохранение истории успеха в в log файл

**Используем модули:**
1) re - библиотека для работы с регулярными(шаблонными) выражениями
2) glob - модуль работы с файлами и каталогами по шаблону

# A program for studying file operations

**Performs the following tasks:**
1) Searching for all files in the current directory with the name 'task_*' and the extension 'md'
2) Extracting blocks from each file: "Task number", "Task", and "Solution"
3) At the first stage: writing these blocks to a file (in subsequent stages, to a database)
4) Saving the success history to a log file

**We use the following modules:**
1) re — a library for working with regular (pattern) expressions
2) glob — a module for working with files and directories based on a pattern
